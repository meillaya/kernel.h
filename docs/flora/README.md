# tikz-flora

Vendored copy of the tikz-flora package from
[https://flora.alpacasoft.dev/](https://flora.alpacasoft.dev/), retrieved
2026-10-31. It grows watercolour flora in LuaLaTeX page margins.

The package is loaded by `docs/report.tex`. `.latexmkrc` adds `docs/flora` to
`TEXINPUTS`, so no installation is needed.
